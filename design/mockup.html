Notes for Atlas and David. The six required screen groups are covered: auth (sign in, sign up), dashboard, new customer form + profile detail with applicable policies, per-customer policy select with PDF generation and a wa.me share button that prefills the PDF link, the demo payment page at /pay/[paymentId] with a Pay action that marks the policy active and triggers the Resend confirmation email, and the success state. Two reference screens added for context: product catalogue and an empty state. Design uses a tight, neutral system (Tailwind + shadcn/ui aesthetic) matching the chosen stack, with a single accent (blue) for action, semantic colours for status badges, and accessible focus rings. The Figma version is blocked behind a Starter plan MCP call limit and a View seat; once either is lifted, the same screens will be rebuilt as Align UI component instances on a new page in the design system file.
